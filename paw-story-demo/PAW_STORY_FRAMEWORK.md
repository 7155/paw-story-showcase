# PAW 官网叙事框架

## 核心命题

PAW 不是“功能很多的 Agent 平台”，而是一个连续的个人上下文系统：人的输入进入系统，经过受治理的记忆与项目知识，被浏览器和 Agent 用于真实工作，最终结果再次留下可核查的项目事实。

## 页面节奏

1. **Hero / 世界观**：暗色星空代表项目空间，PAW 是中心运行时，Room、Memory、Knowledge、Browser 与 Agents 是可进入的对象。
2. **智能输入**：以文档写作为真实场景，逐帧回放输入、界面上下文、记忆召回、生成和 Tab 插入。
3. **OS 记忆**：展示 `来源 → 整理 → 记忆 → 主题`，强调治理、来源与可撤销，而非自动保存一切。
4. **多 Agent**：以星系隐喻 Room。中心是目标，轨道是执行线，Agent 节点并行工作，证据最终回到 Room。
5. **知识库**：个人记忆与项目材料分开；展示材料、图谱、检索命中与打开来源。
6. **沙盒浏览器**：展示标签页、页面现场、Agent 轨迹、快照和写操作授权边界。
7. **Closing / 闭环**：输入、记忆、知识、浏览与 Agent 不是五项功能，而是同一条可继续的上下文链。

## 参考迁移

- 从 Tutti 借用：大产品实景、轻文案、每一幕直接展示产品状态。
- 从 VCP 借用：一屏一个中心命题、连续章节、世界观驱动的产品叙事。
- PAW 自己的视觉语言：暗色星空桌面 + 暖白工作台；细边框、微阴影、墨绿强调；星空只用于 Room / Agent / 项目关系，不作为无意义装饰。

## 前端原则

- 全部内容使用 DOM / React / CSS / SVG，禁止录屏替代。
- 复用 PAW 源码中的真实状态、字段与交互命名。
- 演示可暂停、重播、响应式缩放，并支持 `prefers-reduced-motion`。
- 官网演示属于产品解释，不冒充已完成的真实前台验收；最终上线前仍需用安装后的 PAW 进行前景验证。
